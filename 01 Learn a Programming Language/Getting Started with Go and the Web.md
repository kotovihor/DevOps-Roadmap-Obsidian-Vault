## Чому варто обирати Go для веб-розробки?
- **Go**, або **Golang**, стає все більш популярною мовою для серверної розробки. Її часто використовують як альтернативу таким технологіям, як **PHP, Node.js, Ruby та Python**.
- Однією з головних переваг **Go** є **низьке споживання ресурсів**. Завдяки цьому розробники можуть створювати потужні веб-додатки та розміщувати їх навіть на недорогій або слабшій інфраструктурі.
- Go є **статично типізованою компільованою мовою**, створеною компанією **Google**. Вона розроблялася з акцентом на простоту, високу продуктивність та зручну роботу з паралельними процесами.
## Початок роботи з Go
- Перед тим як розпочати веб-розробку на **Go**, потрібно виконати кілька підготовчих кроків.
### Встановлення Go
1. Спочатку потрібно завантажити та встановити **Go** на свій комп’ютер. Найкраще робити це з офіційного сайту мови програмування **Go**.
2. Після встановлення варто перевірити, чи правильно налаштоване середовище. Для цього в терміналі можна виконати команду:
```Bash
go version
```
- Якщо **Go** встановлено правильно, у терміналі з’явиться версія мови.
### Базові знання HTML
- Для створення веб-додатків потрібно розуміти основи **HTML**. HTML відповідає за структуру веб-сторінки: заголовки, текст, посилання, форми, кнопки та інші елементи.
### Розуміння HTTP
- Також важливо мати базове розуміння протоколу **HTTP**. Саме HTTP використовується для обміну даними між клієнтом, наприклад браузером, і сервером.
- Наприклад, коли користувач відкриває сайт, браузер надсилає **HTTP-запит** до сервера, а сервер повертає відповідь із потрібною сторінкою або даними.
## Перша програма на Go
- Почати роботу з Go можна зі створення простого файлу **main.go**.
- Приклад програми:
```Go
package main

import "fmt"

func main() {
	fmt.Println("Hello, World!")
}
```
- Щоб запустити програму, потрібно відкрити термінал у папці з файлом і виконати команду:
```Bash
go run main.go
```
- Якщо все налаштовано правильно, у терміналі з’явиться повідомлення:
```Bash
Hello, World!
```
### Структура файлу `main.go`
- Файл першої програми зазвичай має назву **main.go**. У ньому міститься основний код, з якого починається виконання програми.
#### `package main`
```Go
package main
```
- Кожна програма на **Go** починається з оголошення пакета. Пакет **main** є особливим. Він показує компілятору, що цей файл є частиною виконуваної програми. Саме з пакета `main` можна створити програму, яку користувач запускає на комп’ютері.
- Якщо замість `main` використати інший пакет, такий файл буде розглядатися як частина бібліотеки, а не як самостійна програма.
#### `import "fmt"`
```Go
import "fmt"
```
- Ключове слово **import** використовується для підключення пакетів.
- У цьому прикладі підключається пакет **fmt** зі стандартної бібліотеки **Go**. Він використовується для форматування та виведення тексту.
- Саме завдяки пакету `fmt` ми можемо використовувати команду:
```Go
func main() {
	fmt.Println("Hello, World!")
}
```
#### `func main()`
```Go
func main() {
	fmt.Println("Hello, World!")
}
```
- Функція **`main`** — це головна функція програми. Саме з неї починається виконання коду.
- Коли ми запускаємо програму, **Go** знаходить функцію **`main()`** і виконує команди, які розміщені всередині її фігурних дужок `{ }`.
#### `fmt.Println("Hello, World!")`
```Go
fmt.Println("Hello, World!")
```
- Цей рядок виводить текст **“Hello, World!”** у консоль.
- `Println` означає **“print line”**, тобто вивести рядок тексту з переходом на новий рядок.
### Запуск програми
- Щоб запустити програму, потрібно відкрити термінал у папці з файлом **main.go** і виконати команду:
```Bash
go run main.go
```
- Команда **`go run`** виконує дві дії:
	1. компілює програму;
	2. одразу запускає її.
- Якщо код написано правильно, у терміналі з'явиться результат:
```Bash
Hello, World!
```

## Створення простого веб-сервера
- **Перший етап** — це створення базового веб-сервера. На цьому рівні **Go** використовується для виведення простого тексту, наприклад **“Hello, World!”**, безпосередньо на веб-сторінку.
```Go
package main  
  
import "net/http"  
import "fmt"  
  
func main() {  
    http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {  
       fmt.Fprintf(w, "<h1>Hello, World</h1>")  
    })  
  
    http.ListenAndServe(":80", nil)  
}
```
- Цей етап допомагає зрозуміти, як **Go** приймає **HTTP-запит** від браузера та повертає відповідь користувачу.
### Розбір мінімального вебсервера на Go
#### Оголошення пакета
```Go
package main
```
- `package main` вказує компілятору, що цей файл є частиною виконуваної програми, а не бібліотеки.
- У **Go** саме пакет `main` використовується для створення програми, яку можна запустити на комп'ютері.
#### Імпорт пакетів
```Go
import "net/http"
import "fmt"
```
- У програмі підключаються два пакети зі стандартної бібліотеки **Go**.
##### Пакет `net/http`
- Пакет `net/http` використовується для роботи з протоколом **HTTP**. Він містить інструменти для створення вебсервера, обробки запитів і надсилання відповідей користувачу.
##### Пакет `fmt`
- Пакет `fmt` використовується для форматованого введення та виведення. У цьому коді він застосовується для того, щоб відправити **HTML-код** безпосередньо у відповідь браузеру.
#### Головна функція `main`
```Go
func main() {
```
- Функція `main()` є точкою входу в програму. Саме з неї починається виконання коду після запуску програми.
- Усередині цієї функції налаштовується логіка роботи вебсервера.
#### Реєстрація маршруту
```Go
http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
```
- Функція `http.HandleFunc()` визначає, як сервер має реагувати на певну адресу.
- **Перший параметр:** `"/"` позначає головну сторінку сайту.
- **Другий параметр** — це анонімна функція, яка виконується тоді, коли користувач відкриває цю сторінку.
#### Параметри обробника
```Go
func (w http.ResponseWriter, r *http.Request)
```
- У цієї функції є два основні параметри.
##### `w http.ResponseWriter`
- `w` використовується для надсилання відповіді користувачу. Через нього сервер відправляє текст, HTML-код або інші дані у браузер.
##### `r *http.Request`
- `r` містить інформацію про запит від браузера. Наприклад, через нього можна отримати адресу сторінки, метод запиту, параметри форми або інші дані користувача.
- У цьому прикладі параметр `r` не використовується, але він обов’язково передається в обробник.
#### Відправка HTML-контенту
```Go
fmt.Fprintf(w, "<h1>Hello, World!</h1>")
```
- Цей рядок записує HTML-код у відповідь браузеру.
- Тег `<h1>` створює великий заголовок першого рівня. Тому в браузері користувач побачить напис.
#### Запуск сервера
```Go
http.ListenAndServe(":80", nil)
```
- Цей рядок запускає вебсервер і змушує його слухати вхідні підключення. Порт `80` є стандартним портом для HTTP. Після запуску програми сторінку можна відкрити в браузері за адресою: `http://localhost`
- Однак для навчальних прикладів часто зручніше використовувати порт `8080`, оскільки порт `80` іноді потребує прав адміністратора.
```Go
http.ListenAndServe(":8080", nil)
```
- Тоді сторінку потрібно відкривати за адресою: `http://localhost:8080`
## Динамічне привітання
- **Наступний етап** — створення динамічних сторінок. На відміну від статичної сторінки, динамічна сторінка може змінювати свій вміст залежно від дій або введених даних користувача.
```Go
package main

import "fmt"
import "net/http"

func main() {
    http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
        if r.FormValue("q") != "" {
            fmt.Fprintf(w, `
                <body>
                    <h1>Hello, %s</h1>
                </body>
            `, r.FormValue("q"))
            return
        }
        fmt.Fprintf(w, `
            <body>
                <form action="/" method="GET">
                    <label>Enter your name</label>
                    <input name="q">
                    <button type="submit">Submit</button>
                </form>
            </body>
        `)
    })

    http.ListenAndServe(":80", nil)
}
```
- На цьому етапі **Go** вже не просто показує готовий текст, а обробляє дані, які надходять від користувача.
### Оголошення пакета
```Go
package main
```

- Рядок `package main` означає, що цей файл є частиною виконуваної програми. У **Go** пакет `main` використовується тоді, коли ми хочемо створити програму, яку можна запустити самостійно.
### Імпорт пакетів

#### `net/http`
- Пакет `net/http` використовується для роботи з HTTP-протоколом. Саме він дозволяє створити вебсервер, приймати запити від браузера та надсилати відповіді користувачу.
### Головна функція `main`
```Go
func main() {
```

- Функція `main()` є точкою входу в програму.
- Коли ми запускаємо файл командою:
```Bash
go run main.go
```
- **Go** починає виконання саме з функції `main()`.
### Реєстрація обробника сторінки
```Go
http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
```
- Функція `http.HandleFunc()` реєструє обробник для певної адреси. У цьому випадку адреса `"/"` означає головну сторінку сайту.
- Тобто коли користувач відкриває `http://localhost` сервер виконує код, який знаходиться всередині цієї функції.
### Параметри `w` та `r`
```Go
func(w http.ResponseWriter, r *http.Request)
```
- У функції-обробнику є два важливі параметри.
#### `w http.ResponseWriter`
- `w` використовується для надсилання відповіді браузеру. Через нього сервер може відправити текст, HTML-код або інші дані.
#### `r *http.Request`
- `r` містить інформацію про запит користувача. Через нього можна отримати:
	- параметри з форми;
	- адресу сторінки;
	- метод запиту;
	- заголовки;
	- cookies.
- У цьому коді `r` використовується для отримання значення з поля форми.
### Отримання даних з форми
```Go
r.FormValue("q")
```
- Цей рядок отримує значення параметра з назвою `q`. У HTML-формі є поле:
```HTML
<input name="q">
```
- Саме атрибут `name="q"` визначає назву параметра, який буде переданий на сервер.
- Наприклад, якщо користувач введе ім’я `Ihor`, браузер відправить запит приблизно такого вигляду: `http://localhost/?q=Ihor`
- Після цього **Go** може отримати значення `Ihor` через:
```Go
r.FormValue("q")
```
### Умова `if`
```Go
if r.FormValue("q") != "" {
```
- Ця умова перевіряє, чи ввів користувач ім’я. Якщо значення `q` не порожнє, тобто користувач щось ввів у форму, виконується блок коду всередині `if`.
### Виведення персонального привітання
```Go
fmt.Fprintf(w, `
    <body>
        <h1>Hello, %s</h1>
    </body>
`, r.FormValue("q")) return
```
- Цей код відправляє у браузер HTML-сторінку з персоналізованим привітанням.
- `%s` — це місце, куди підставляється рядок, тобто ім’я користувача.
- Команда `return` завершує виконання обробника, щоб код нижче вже не виконувався.
### Виведення HTML-форми
```Go
fmt.Fprintf(w, `
    <body>
        <form action="/" method="GET">
            <label>Enter your name</label>
            <input name="q">
            <button type="submit">Submit</button>
        </form>
    </body>
`)
```
- Ця форма складається з кількох елементів:
	- `<form action="/" method="GET"> ` — цей тег створює форму.
		- `action="/"` означає, що після натискання кнопки дані будуть відправлені на головну сторінку.
		- `method="GET"` означає, що дані будуть передані через URL-адресу.
	- `<label>Enter your name</label>` — це текстова підказка для користувача. Вона пояснює, що потрібно ввести ім’я.
	- `<input name="q">` — це поле для введення тексту. Атрибут `name="q"` дуже важливий, тому що саме за цією назвою **Go** потім отримує введене значення.
	- `<button type="submit">Submit</button>` — це кнопка для відправлення форми. Після натискання кнопки браузер надсилає запит на сервер.
## Програма-лічильник
- Програма **Counter** є фінальним етапом базового посібника з веб-розробки на Go. Вона демонструє глибшу взаємодію користувача з сервером і показує, як веб-додаток може зберігати та змінювати дані під час роботи.
### Призначення програми
- Основна мета цього прикладу — показати, як **Go** може використовуватися для створення інтерактивних (взаємодія в реальному часі) вебсторінок.
- На попередніх етапах програма лише виводила текст або обробляла введене ім’я користувача. У прикладі з лічильником веб-додаток уже працює зі **станом**.
- **Стан додатка** — це дані, які можуть змінюватися під час роботи програми. У цьому випадку таким станом є значення лічильника.
### Інтерфейс користувача
- Після відкриття сторінки в браузері користувач бачить простий інтерфейс:
	- текстову мітку **Counter**;
	- поле введення з поточним числом;
	- кнопку **Add**.
- За замовчуванням у полі може відображатися число `1`
- Користувач натискає кнопку **Add**, після чого значення лічильника збільшується.
### Логіка роботи програми
- Кожного разу, коли користувач натискає кнопку **Add**, браузер надсилає запит до сервера.
- **Сервер на Go:**
	1. отримує поточне значення лічильника;
	2. збільшує його на одиницю;
	3. формує оновлену HTML-сторінку;
	4. повертає її назад у браузер.
### Розбір програми-лічильника на Go
```Go
package main

import "fmt"
import "strconv"
import "net/http"

func main() {
    http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
        if r.Method == "POST" {
            count, _ := strconv.Atoi(r.FormValue("counter"))
            count++

            fmt.Fprintf(w, `
            <body>
                <form action="/" method="POST">
                    <label>Counter</label>
                    <input name="counter" value="%d" readonly>
                    <button type="submit">Add</button>
                </form>
                <a href="/">Reset</a>
            </body>
        `, count)
            return
        }

        fmt.Fprintf(w, `
            <body>
                <form action="/" method="POST">
                    <label>Counter</label>
                    <input name="counter" value="1" readonly>
                    <button type="submit">Add</button>
                </form>
                <a href="/">Reset</a>
            </body>
        `)
    })

    http.ListenAndServe(":80", nil)
}
```

```Go
http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request))
```
- Функція `http.HandleFunc()` реєструє обробник для головної сторінки сайту.
- Символ `"/"` означає головну сторінку сайту. Тобто коли користувач відкриває `http://localhost` сервер виконує код, який знаходиться всередині цієї функції.
#### Параметри `w` та `r`
```Go
func (w http.ResponseWriter, r *http.Request)
```
- У функції-обробнику є два параметри.
##### `w http.ResponseWriter`
- `w` використовується для надсилання відповіді браузеру. Через нього сервер повертає HTML-код користувачу.
##### `r *http.Request`
- `r` містить інформацію про запит користувача.
- Через нього можна отримати:
	- метод запиту;
	- дані з форми;
	- URL-адресу;
	- заголовки;
	- інші параметри запиту.
- У цій програмі `r` використовується для перевірки методу запиту і отримання значення лічильника.
#### Перевірка методу запиту
```Go
if r.Method == "POST" {
```
- Цей рядок перевіряє, яким методом користувач звернувся до сервера.
- У програмі є два основні варіанти: `GET` і `POST`
##### GET-запит
- **GET-запит** виконується тоді, коли користувач просто відкриває сторінку в браузері.
- Наприклад: `http://localhost`
- У цьому випадку програма показує початкове значення лічильника `1`
##### POST-запит
- **POST-запит** виконується тоді, коли користувач натискає кнопку **Add**.
- Форма має такий атрибут: `method="POST"`
- Тому після натискання кнопки браузер надсилає дані на сервер методом **POST**.
#### Отримання значення лічильника
```Go
count, _ := strconv.Atoi(r.FormValue("counter"))
```
- Цей рядок отримує значення з поля форми:
```HTML
<input name="counter" value="1" readonly>
```
- Назва поля:
```HTML
name="counter"
```
- Саме тому в **Go** використовується:
```Go
r.FormValue("counter")
```
- Але значення з форми приходить як текст. Наприклад: `"1"`
- Щоб збільшити його на одиницю, потрібно перетворити **текст у число**. Для цього використовується:
```Go
strconv.Atoi(...)
```
- `Atoi` означає перетворення **рядка в ціле число**.
##### Чому треба `strconv.Atoi`
- Значення з HTML-форми приходить як текст. Наприклад: `"1"`
- Але щоб зробити `count++` потрібно мати число, а не текст. Не можна нормально збільшити текст `"1"` як число. Тому його треба перетворити. Для цього використовується пакет `strconv` і функція `strconv.Atoi(...)`
> [!NOTE] Atoi (ASCII to Integer)
> У Go, `strconv.Atoi`— це стандартна функція, яка використовується для перетворення рядка в ціле число.
##### Що повертає `strconv.Atoi`
- Функція `strconv.Atoi()` повертає **два значення**: `number, error`
- **Наприклад:**
```Go
count, err := strconv.Atoi("1")
```
- Тут `count` отримає число `1`, а `err` отримає інформацію про помилку, якщо перетворення не вдалося.
##### Що означає `_`
```Go
count, _ := strconv.Atoi(r.FormValue("counter"))
```
- Символ `_` в Go називається **Blank Identifier**, тобто **порожній ідентифікатор**.
###### Що таке ідентифікатор?
- **Ідентифікатор** — це назва, яку програміст дає елементам програми (змінної, масиву, структури, функції тощо).
###### Для чого потрібен `_`
- У **Go** не можна створювати змінні, які потім не використовуються.
- Якщо нам не потрібне якесь значення, ми можемо записати його в `_`.
###### Приклад з кодом
```Go
count, _ := strconv.Atoi(r.FormValue("counter"))
```
- Функція `strconv.Atoi()` повертає **два значення**: `число, помилка`
- **Повний варіант виглядав би так:**
```Go
count, err := strconv.Atoi(r.FormValue("counter"))
```
- Але якщо ми не хочемо обробляти помилку, можемо написати:
```Go
count, _ := strconv.Atoi(r.FormValue("counter"))
```
- Тобто `count` отримує число, а `_` ігнорує помилку.
###### Що важливо запам'ятати
- `_` — це не **звичайна змінна**. У неї можна **покласти** значення, але потім ці значення неможливо використати. Тому що `_` **не зберігає значення** для подальшого використання.
##### Що означає `:=`
- **Оператор** `:=` означає коротке оголошення змінної.
- Тобто цей рядок:
	- Створює нову змінну `count` і одразу записує в неї результат.
```Go
count, _ := strconv.Atoi(r.FormValue("counter"))
```
#### Збільшення лічильника
```Go
count++
```
- Цей рядок збільшує значення змінної `count` на одиницю.
- Кожне натискання кнопки **Add** збільшує лічильник.
#### Виведення оновленого значення
```Go
fmt.Fprintf(w, `
    <body>
        <form action="/" method="POST">
            <label>Counter</label>
            <input name="counter" value="%d" readonly>
            <button type="submit">Add</button>
        </form>
        <a href="/">Reset</a>
    </body>
`, count)
```
- Цей код формує HTML-сторінку з оновленим значенням лічильника.
- `%d` — це місце, куди підставляється ціле число.
- Наприклад, якщо `count` дорівнює `2`, то браузер отримає:
```HTML
<input name="counter" value="2" readonly>
```
- Якщо `count` дорівнює `3`, то буде:
```HTML
<input name="counter" value="3" readonly>
```
#### Команда `return`
```Go
return
```
- Команда `return` завершує виконання обробника.
- Вона потрібна для того, щоб після обробки **POST-запиту** програма не перейшла нижче до коду, який показує початкову форму.
#### Початкова форма
```Go
fmt.Fprintf(w, `
    <body>
        <form action="/" method="POST">
            <label>Counter</label>
            <input name="counter" value="1" readonly>
            <button type="submit">Add</button>
        </form>
        <a href="/">Reset</a>
    </body>
`)
```
- Цей блок виконується тоді, коли користувач просто відкриває сторінку.
- У цьому випадку сервер показує початкове значення лічильника: `1`
- Поле має атрибут: `readonly`. Це означає, що користувач бачить значення, але не може редагувати його вручну.
#### Кнопка Add
```HTML
<button type="submit">Add</button>
```
- Ця кнопка відправляє форму на сервер. Оскільки форма має `method="POST"` , після натискання кнопки сервер отримує **POST-запит**.
#### Посилання Reset
```HTML
<a href="/">Reset</a>
```
- Це посилання повертає користувача на головну сторінку.
- Коли користувач натискає **Reset**, браузер виконує звичайний GET-запит на адресу: `"/"`, тому програма знову показує початкове значення `1`
#### Запуск сервера
```Go
http.ListenAndServe(":80", nil)
```
- Цей рядок запускає вебсервер на порту `80`. Після запуску програми сайт можна відкрити в браузері за адресою: `http://localhost`
##### Що таке `http.ListenAndServe`
- Функція має такий вигляд:
```Go
http:ListenAndServe(addr string, handler Handler)
```
- Тобто вона приймає два параметри:
```Go
http.ListenAndServe(":80", nil)
```
###### Перший параметр
- `":80"` — це порт, на якому буде працювати сервер.
- Порт `80` — стандартний порт для HTTP.
###### Другий параметр
- `nil` — це **handler**, тобто обробник запитів. **Handler** відповідає за те, **як сервер має реагувати на запити користувача**.
######  `nil` у мові Go
- У мові **Go** `nil` — це спеціальний **попередньо оголошений ідентифікатор**, який означає відсутність значення для певних типів даних.
- Його можна розуміти як: "тут немає об'єкта, змінна ні на що не посилається, значення відсутнє,"
###### Чому можна передати `nil`
- Цей рядок реєструє обробник для **головної сторінки** `/`:
```Go
http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "<h1>Hello, World!</h1>")
})
```
- Коли використовуємо `http.HandleFunc(...)` без створення власного маршрутизатора, Go автоматично додає цей маршрут у стандартний маршрутизатор `http.DefaultServeMux`
