- **Змінні** — це важливе поняття в програмуванні, яке необхідно опанувати. Це символи, що позначають певні значення, які використовуються в програмі.
## Що таке змінна
- **Змінна** — це іменоване місце в пам’яті комп’ютера, у якому зберігається певне значення. Простими словами, **змінна** — це **назва для значення**, яке ми хочемо використовувати в програмі.
- Наприклад, якщо в програмі часто потрібно використовувати число:
```Go
1032049348
```
- Незручно кожного разу писати його повністю. Тому це значення можна зберегти у **змінну**:
```Go
i := 1032049348
```
- Тепер замість числа `1032049348` можна використовувати ім’я **змінної** `i`.
### Змінна як "ярлик"
- Змінну можна уявити як ярлик, який прикріплюється до певного значення.
- **Наприклад**:
	- `i` — це назва ярлика;
	- `1032049348` — це значення;
	- змінна `i` дозволяє звертатися до цього значення в програмі.
```Go
i := 1032049348
```
- Тобто **змінна** несе не саме ім’я, а значення, яке з цим ім’ям пов’язане.
### Оголошення змінної в Go
- У Go **змінну** можна створити за допомогою короткого оператора оголошення:
```Go
i := 1032049348
```
- Цей запис означає: створити **змінну** `i` і присвоїти їй значення `1032049348`.

| Частина      | пОЯСНЕННЯ                               |
| ------------ | --------------------------------------- |
| `i`          | ім’я змінної                            |
| `:=`         | коротке оголошення та присвоєння        |
| `1032049348` | значення змінної                        |
| `int`        | тип даних, який Go визначає автоматично |
- **Go** сам розуміє, що число `1032049348` є цілим числом, тому тип **змінної** буде `int`.
### Ініціалізація змінної
- **Ініціалізація** — це момент, коли змінній уперше присвоюється значення.
- Наприклад:
```Go
i := 1032049348
```
- У цьому рядку **змінна** `i` створюється і одразу отримує значення.
- Після ініціалізації **змінну** можна використовувати в програмі замість самого значення.
### Виведення змінної на екран
- Щоб вивести значення **змінної**, можна використати функцію `fmt.Println()`.
- Приклад:
```Go
package main

import "fmt"

func main() {
    i := 1032049348
    fmt.Println(i)
}
```
- Результат: `1032049348`
- Програма виводить не букву `i`, а значення, яке зберігається у **змінній** `i`.
### Використання змінної в обчисленнях
- **Змінні** можна використовувати у математичних операціях.
- Наприклад:
```Go
i := 1032049348
fmt.Println(i - 813)
```
- Тут Go бере значення **змінної** `i` і віднімає від нього `813`.
- Результат: `1032048535`
### Змінна може зберігати результат обчислення
- **Змінній** можна присвоїти не тільки готове значення, а й результат математичного виразу.
- Наприклад:
```Go
x := 76 + 145
```
- Спочатку Go обчислює:
```Go
76 + 145 = 221
```
- Потім результат `221` записується у **змінну** `x`.
- Повний приклад:
```Go
package main

import "fmt"

func main() {
    x := 76 + 145
    fmt.Println(x)
}
```
- Результат: `221`
### Правило лівої сторони
- У Go під час присвоєння **змінна**, яка отримує значення, пишеться **зліва**.
- Правильно:
```Go
x := 76 + 145
```
- Тут `x` стоїть зліва, тому що саме в неї записується результат обчислення.
- А справа знаходиться значення або вираз:
```Go
76 + 145
```
### Типи даних у змінних
- **Змінні** в Go можуть зберігати різні типи даних.
```Go
s := "Hello, World!"
f := 45.06
b := 5 > 9
array := [4]string{"item_1", "item_2", "item_3", "item_4"}
slice := []string{"one", "two", "three"}
m := map[string]string{"letter": "g", "number": "seven", "symbol": "&"}
```

| ПРИКЛАД                       | Тип даних | Пояснення               |
| ----------------------------- | --------- | ----------------------- |
| `s := "Hello, World!"`        | `string`  | рядок / текст           |
| `f := 45.06`                  | `float64` | дробове число           |
| `b := 5 > 9`                  | `bool`    | логічне значення        |
| `array := [4]string{...}`     | array     | масив                   |
| `slice := []string{...}`      | slice     | зріз                    |
| `m := map[string]string{...}` | map       | структура ключ-значення |
### Логічні значення
- У Go логічний тип даних називається `bool`. Він може мати тільки два значення: `true` і `false`.
- Наприклад:
```Go
b := 5 > 9
```
- Оскільки `5` не більше за `9`, результат буде `false`.
### Приклад зі слайсом
- **Слайс** — це набір значень одного типу.
- Приклад:
```Go
slice := []string{"one", "two", "three"}
```
- Тут створюється змінна `slice`, яка зберігає три рядки: `one, two, three`
```Go
package main

import "fmt"

func main() {
    slice := []string{"one", "two", "three"}
    fmt.Println(slice)
}
```
### Змінні та пам’ять комп’ютера
- На технічному рівні **змінна** пов’язана з пам’яттю комп’ютера. Коли ми пишемо: `i := 1032049348` комп’ютер виділяє невелику область пам’яті, у якій зберігається це число. Ім’я змінної `i` дозволяє програмі звертатися до цього місця в пам’яті. Тобто змінна — це не просто назва, а спосіб доступу до збереженого значення.
## Способи оголошення змінних
- У мові Go є кілька способів оголошення змінних. Змінну можна:
1. оголосити без початкового значення;
2. оголосити і одразу присвоїти значення;
3. оголосити коротким способом через `:=`.
### Оголошення змінної без ініціалізації
- Якщо ми хочемо створити **змінну**, але поки не задавати їй значення, використовуємо ключове слово `var`.
```Go
var i int
```
- У цьому випадку Go створює **змінну** `i` типу `int`.  Навіть якщо ми не вказали значення, Go все одно дасть **змінній нульове значення** для її типу. Для `int` нульове значення — це `0`.
### Довге оголошення з ініціалізацією
- Можна одразу оголосити змінну і присвоїти їй значення:
```Go
var i int = 1
```
- Це називається **довга форма оголошення змінної**. Але в Go такий запис використовується рідше, якщо значення присвоюється одразу.
### Коротке оголошення змінної
- Найчастіше в Go використовують короткий запис:
```Go
i := 1
```
- У цьому випадку ми не пишемо тип `int`, тому що Go сам визначає тип за значенням. Тобто Go бачить число `1` і розуміє, що змінна `i` має тип `int`.
### Різниця між `var` і `:=`
|Запис|Коли використовувати|
|---|---|
|`var i int`|коли потрібно оголосити змінну без початкового значення|
|`var i int = 1`|коли потрібно явно вказати тип і значення|
|`i := 1`|коли потрібно швидко створити змінну зі значенням|
### Прийняті правила в Go
- У спільноті Go є свої правила стилю.
#### Якщо змінна не має початкового значення
- Тоді краще писати так:
```Go
var i int
```
- Наприклад:
```Go
var count int
```
- Це означає, що змінна буде використана пізніше.
#### Якщо змінна одразу отримує значення
- Тоді краще писати коротко:
```Go
i := 1
```
- Тобто в Go краще уникати зайвого коду, якщо тип очевидний.
### Явне задання типу при короткому оголошенні
- Іноді ми не хочемо, щоб Go сам вибирав тип.
- Наприклад, в `i := 1`, тут Go автоматичне вибере тип `int`. Але якщо нам потрібен саме тип `int64`, можна написати так:
```Go
i := int64(1)
```
- Тут `int64(1)` — це явне перетворення значення до типу `int64`.
### Чому не завжди пишуть `var i int = 1`
- Запис `var i int = 1` є правильним, але в Go він вважається менш зручним, якщо тип і так зрозумілий.
- Краще писати `i := 1` тому що цей варіант:
	- коротший;
	- легше читається;
	- відповідає стилю Go;
	- не дублює очевидну інформацію.
### Приклад різних способів
```Go
package main

import "fmt"

func main() {
    var a int
    var b int = 10
    c := 20
    d := int64(30)

    fmt.Println(a)
    fmt.Println(b)
    fmt.Println(c)
    fmt.Println(d)
}
```

|Змінна|Запис|Пояснення|
|---|---|---|
|`a`|`var a int`|оголошена без значення, тому має `0`|
|`b`|`var b int = 10`|оголошена з явним типом і значенням|
|`c`|`c := 20`|коротке оголошення, тип визначає Go|
|`d`|`d := int64(30)`|коротке оголошення з явним типом `int64`|
## Нулові значення
### Що таке нульове значення
- У Go кожен вбудований тип даних має своє **нульове значення**.
- **Нульове значення** — це стандартне значення, яке автоматично отримує змінна, якщо ми її оголосили, але не присвоїли їй конкретне значення.
```Go
var a int
```
- Ми створили змінну `a` типу `int`, але не записали в неї число. У такому випадку Go автоматично присвоїть їй значення `0`.
### Приклад нульових значень
```Go
package main

import "fmt"

func main() {
    var a int
    var b string
    var c float64
    var d bool

    fmt.Printf("var a %T = %+v\n", a, a)
    fmt.Printf("var b %T = %q\n", b, b)
    fmt.Printf("var c %T = %+v\n", c, c)
    fmt.Printf("var d %T = %+v\n\n", d, d)
}
```
- Результат:
```Go
var a int = 0
var b string = ""
var c float64 = 0
var d bool = false
```
#### Що таке `fmt.Printf`
- `fmt.Printf()` — це функція для **форматованого виведення тексту**. Тобто вона дозволяє виводити не просто готовий текст, а текст із підстановкою значень.
- `fmt.Println()` — просто виводить значення на екран.
- Наприклад:
```Go
fmt.Printf("Hello, %s", "Igor")
```
- Результат:
```Go
Hello, Igor
```
- Тут `%s` — це місце, куди підставиться текст `"Igor"`.
#### Розбір першого рядка
```Go
fmt.Printf("var a %T = %+v\n", a, a)
```
- Тут є дві частини:
```Go
"var a %T = %+v\n" // Це шаблон виведення
```
```Go
a, a // Це значення, які підставляються замість `%T` і `%+v`.
```
##### Що означає `%T`
- У мові програмування Go специфікатор `%T` — це спеціальний символ форматування, який використовується у функціях пакету `fmt` (наприклад, `fmt.Printf`) для виведення типу даних (Type) змінної або значення у синтаксисі Go .
- Наприклад:
```Go
var a int  
fmt.Printf("%T", a)
```
- Результат: `int`. Тобто `%T` показує, що змінна `a` має тип `int`.
##### Що означає `%+v`
- `%+v` — означає вивести значення змінної у стандартному вигляді. Наприклад:
```Go
var a int
fmt.Printf("%+v", a)
```
- Результат `0`, тому що нульове значення для `int` — це `0`.
##### Що означає `\n`
- `\n` — перейти на новий рядок.
- Наприклад:
```Go
fmt.Printf("Hello\nWorld")
```
- Результат:
```Go
Hello
World
```
##### Повний розбір рядка
```Go
fmt.Printf("var a %T = %+v\n", a, a)
```
- `%T` замінюється на `int`;
- `%+v` замінюється на `0`;
- `\n` переносить курсор на новий рядок.
##### Чому `a` написано два рази
- Тому що в шаблоні є два форматні місця: `%T` і `%+v`.
- Перше `a` підставляється в `%T` і показує тип.
- Друге `a` підставляється в `%+v` і показує значення.
#### Що означає `%q`
- `%q` означає вивести рядок у лапках. Якби ми написали `%+v`, то порожній рядок було б важко побачити, бо він просто нічого не вивів би. А `%q` показує лапки, тому видно, що це саме порожній рядок.
#### Загальна схема
```Go
fmt.Printf("текст %T текст %+v\n", змінна, змінна)
```
- Означає вивести тип змінної і її значення.
#### Головні позначення
|Запис|Значення|
|---|---|
|`fmt.Printf()`|форматоване виведення|
|`%T`|показати тип змінної|
|`%+v`|показати значення змінної|
|`%q`|показати рядок у лапках|
|`\n`|перехід на новий рядок|
|`\n\n`|два переходи, тобто порожній рядок після виведення|
### Нульові значення основних типів
| Тип даних | Нульове значення | Пояснення                         |
| --------- | ---------------: | --------------------------------- |
| `int`     |              `0` | ціле число за замовчуванням       |
| `string`  |             `""` | порожній рядок                    |
| `float64` |              `0` | дробове число за замовчуванням    |
| `bool`    |          `false` | логічне значення за замовчуванням |
### Чому в Go немає undefined
- У деяких мовах програмування змінна може мати значення `undefined`, тобто “невизначене значення”.
- У Go такого немає.
- Якщо змінна оголошена, але їй не присвоєно значення, вона все одно отримає нульове значення свого типу.
## Імена змінних
- У Go змінним можна давати різні імена, але потрібно дотримуватися правил синтаксису та стилю. 
- Ім’я змінної має бути зрозумілим, коротким і відповідати тому значенню, яке вона зберігає.
- Наприклад:
```Go
userName := "Ihor"
age := 18
```
- `userName` — ім’я користувача;
- `age` — вік користувача.
### Правила іменування змінних
- Імена змінних у Go мають кілька важливих правил.
#### Ім’я змінної не може містити пробілів
- Правильно:
```Go
userName := "Igor"
```
- Неправильно:
```Go
user name := "Igor"
```
- **Тому що ім’я змінної має бути одним словом.**
#### Ім’я може містити букви, цифри та символ `_`
- Правильно:
```Go
name4 := "Igor"
user_name := "Igor"
```
- Але в Go символ `_` у звичайних іменах змінних використовують рідко, бо стандартний стиль — `camelCase`.
#### Ім’я змінної не може починатися з цифри
- Правильно:
```Go
name4 := "Igor"
```
- Неправильно:
```Go
4name := "Igor"
```
- **Цифри можна використовувати всередині або в кінці імені, але не на початку.**
#### Не можна використовувати дефіси та спеціальні символи
- Неправильно:
```Go
user-name := "Igor"  
$user := "Igor"
```
- **Дефіс** `-` у Go сприймається як знак мінус, а символ `$` не дозволений в іменах змінних.
### Таблиця допустимих і недопустимих імен
| Допустимо  | Недопустимо | Чому недопустимо                |
| ---------- | ----------- | ------------------------------- |
| `userName` | `user-name` | дефіс не дозволений             |
| `name4`    | `4name`     | ім’я не може починатися з цифри |
| `user`     | `$user`     | не можна використовувати `$`    |
| `userName` | `user name` | не можна писати з пробілом      |
### Регістр має значення
- У Go імена змінних **чутливі до регістру**. Це означає, що такі імена будуть різними змінними:
```Go
userName  
USERNAME  
UserName  
uSERnAME
```
- Для Go це не одне й те саме, а чотири різні ідентифікатори.
- Наприклад:
```Go
userName := "Igor"  
UserName := "Oleg"  
  
fmt.Println(userName)  
fmt.Println(UserName)
```
- Результат:
```Go
Igor
Oleg
```
- **Тому краще не створювати дуже схожі імена, бо це може заплутати.**
### Велика літера на початку має особливе значення
- У Go перша літера імені змінної впливає на її доступність.
#### Якщо ім’я починається з великої літери
- Змінна є **експортованою**. Це означає, що її можна використовувати з інших пакетів.
```Go
var Email string
```
- `Email` починається з великої літери, тому ця змінна доступна за межами пакета.
#### Якщо ім’я починається з маленької літери
- Змінна доступна тільки всередині поточного пакета.
```Go
var password string
```
- `password` починається з маленької літери, тому вона доступна тільки в тому пакеті, де була оголошена.
### Короткі імена змінних
- У Go часто використовують короткі імена змінних. Наприклад, якщо є вибір між `userName` і `user`, то часто краще використати `user`, якщо з контексту зрозуміло, що це саме користувач.
### Чим менша область використання, тим коротше ім’я
- Є важливе правило стилю:
> Чим менше місце, де використовується змінна, тим коротшим може бути її ім’я.
- Наприклад:
```Go
names := []string{"Mary", "John", "Bob", "Anna"}

for i, n := range names {
    fmt.Printf("index: %d = %q\n", i, n)
}
```
- `names` — змінна з більшою областю використання, тому має зрозуміле ім’я;
- `i` — індекс у циклі;
- `n` — одне ім’я з колекції `names`.
- Змінні `i` і `n` використовуються тільки всередині циклу, тому короткі імена тут нормальні.
### Розбір прикладу з `range`
```Go
names := []string{"Mary", "John", "Bob", "Anna"}

for i, n := range names {
    fmt.Printf("index: %d = %q\n", i, n)
}
```
- `range names` проходить по кожному елементу слайсу `names`.
- На кожному кроці:
	- `i` отримує індекс елемента;
	- `n` отримує саме значення елемента.

|`i`|`n`|
|--:|---|
|`0`|`"Mary"`|
|`1`|`"John"`|
|`2`|`"Bob"`|
|`3`|`"Anna"`|
- У Go `%d` — це **format verb** для виведення цілих чисел у десятковій системі числення у функціях пакету `fmt`, наприклад `fmt.Printf`, `fmt.Sprintf`.
### Стиль іменування в Go
- У Go для імен із кількох слів зазвичай використовують стиль `mixedCaps` або `MixedCaps`.
- Правильно:
```Go
userName
```
- А не так:
```Go
user_name
```
- У Go символ підкреслення `_` не є стандартним стилем для назв змінних.
#### `mixedCaps` і `MixedCaps`
- У Go є два основні стилі:
	- `mixedCaps` — перше слово починається з маленької літери. Такі імена зазвичай використовуються для змінних, які доступні тільки всередині пакета. Приклади: `userName`, `totalPrice`, `studentAge`.
	- `MixedCaps` — перше слово починається з великої літери. Такі імена можуть бути експортованими, тобто доступними з інших пакетів. Приклади: `UserName`, `TotalPrice`, `StudentAge`.
### Абревіатури в Go
- Абревіатури в Go зазвичай пишуться великими літерами. Наприклад, краще писати: `serveHTTP`, а не `serveHttp`, тому що `HTTP` — це абревіатура. Так само `userID` краще, ніж `userId`.
### Таблиця стилю

|Стандартний стиль|Нестандартний стиль|Чому нестандартний|
|---|---|---|
|`userName`|`user_name`|підкреслення не є типовим стилем Go|
|`i`|`index`|у короткому циклі `i` коротше і звичніше|
|`serveHTTP`|`serveHttp`|абревіатури пишуться великими літерами|
|`userID`|`userId`|`ID` — абревіатура|
## Переприсвоєння змінних у Go
### Що означає переприсвоєння змінної
- Слово **“змінна”** означає, що її значення можна змінювати під час виконання програми. Тобто ми можемо спочатку записати в змінну одне значення, а потім замінити його іншим.
- Наприклад:
```Go
i := 76
i = 42
```
- Спочатку змінна `i` має значення `76`, а потім ми змінюємо її значення на `42`.
### Приклад переприсвоєння
```Go
package main

import "fmt"

func main() {
    i := 76
    fmt.Println(i)

    i = 42
    fmt.Println(i)
}
```
- Результат:
```Go
76
42
```
- `i := 76` — тут ми **створюємо** змінну `i` і присвоюємо їй значення `76`;
- `fmt.Println(i)` — виводимо перше значення змінної `i`;
- `i = 42` — ми вже не створюємо нову змінну, а **змінюємо значення існуючої змінної**.
- `fmt.Println(i)` — виводимо значення змінної `i` після переприсвоювання;
### Різниця між `:=` і `=`
#### `:=` — створення нової змінної
```Go
i := 76
```
- Оператор `:=` використовується тоді, коли ми **вперше створюємо змінну**.
#### `=` — зміна значення існуючої змінної
```Go
i = 42
```
- Оператор `=` використовується тоді, коли змінна вже існує, і ми хочемо просто змінити її значення.
### Правильне використання
- Правильно:
```Go
i := 76  
i = 42
```
- `:=` створює змінну;
- `=` змінює її значення.
- Неправильно:
```Go
i := 76  
i := 42
```
- Тому що друга команда намагається створити змінну `i` ще раз у тому самому блоці коду.
### Помилка `no new variables on left side of :=`
- Якщо написати так:
```Go
i := 5  
i := 10
```
- Go видасть помилку:
```Go
no new variables on left side of :=
```
- Це означає, що зліва від `:=` немає нової змінної. Змінна `i` вже була створена раніше, тому не можна створювати її ще раз через `:=`.
- Правильно треба писати так:
```Go
i := 5  
i = 10
```
### Не можна змінити тип змінної
- У Go змінна має конкретний тип даних. Якщо змінна була створена як `int`, то в неї не можна записати `string`.
- Наприклад:
```Go
i := 72  
i = "Sammy"
```
- Це неправильно. Go автоматично визначив, що `i` має тип `int`. А потім ми намагаємося записати в в `i` текст `"Sammy"`. Текст має тип `string`, тому Go видасть помилку:
```Go
cannot use "Sammy" (type string) as type int in assignment
```
### Правильно: змінювати значення тільки того самого типу
- Якщо змінна типу `int`, можна записувати в неї тільки цілі числа:
```Go
i := 72  
i = 100  
i = 5
```
- Якщо змінна типу `string`, можна записувати в неї тільки рядки:
```Go
name := "Sammy"  
name = "Igor"
```
- Якщо змінна типу `bool`, можна записувати тільки `true` або `false`:
```Go
isReady := true  
isReady = false
```
### Не можна оголосити одну й ту саму змінну двічі
- У Go не можна двічі оголошувати змінну з однаковим ім’ям в одному блоці.
- Наприклад:
```Go
var s string  
var s string
```
- Це помилка. Go виведе помилку:
```Go
s redeclared in this block
```
- Тобто Go не дозволяє створювати дві однакові змінні з одним і тим самим іменем у межах одного блоку коду.
### Різниця між декларацією і переприсвоєнням
#### Декларація
- **Декларація** — це створення нової змінної.
```Go
var s string
```
```Go
i := 5
```
#### Переприсвоєння
- **Переприсвоєння** — це зміна значення вже створеної змінної.
```Go
i = 10
```
- Тут змінна вже існує, ми просто змінюємо її значення.
### Таблиця з необхідною інформацією

|Запис|Що означає|Правильно?|
|---|---|---|
|`i := 5`|створити змінну `i`|так|
|`i = 10`|змінити значення існуючої `i`|так|
|`i := 5` потім `i := 10`|повторно створити `i`|ні|
|`var s string` потім `var s string`|повторно оголосити `s`|ні|
|`i := 72` потім `i = "Sammy"`|змінити `int` на `string`|ні|
## Присвоєння кількох значень у Go
- У Go можна створити кілька змінних і одразу присвоїти їм кілька значень в одному рядку.
- Наприклад:
```Go
j, k, l := "shark", 2.05, 15
```
- Цей запис означає:
> Створи три змінні `j`, `k`, `l` і присвой їм відповідні значення.
### Як Go розподіляє значення
- У такому записі значення присвоюються **по порядку**.
```Go
j, k, l := "shark", 2.05, 15
```

| Змінна | Значення  | Тип       |
| ------ | --------- | --------- |
| `j`    | `"shark"` | `string`  |
| `k`    | `2.05`    | `float64` |
| `l`    | `15`      | `int`     |
- перша змінна `j` отримує перше значення `"shark"`;
- друга змінна `k` отримує друге значення `2.05`;
- третя змінна `l` отримує третє значення `15`.
### Повний приклад програми
```Go
package main

import "fmt"

func main() {
    j, k, l := "shark", 2.05, 15

    fmt.Println(j)
    fmt.Println(k)
    fmt.Println(l)
}
```
- Результат:
```Go
shark  
2.05  
15
```
#### Пояснення результату
- Go автоматично визначає тип кожної змінної.
	- `j` має тип `string`, бо значення `"shark"` — це рядок.
	- `k` має тип `float64`, бо значення `2.05` — це дробове число.
	- `l` має тип `int`, бо значення `15` — це ціле число.
### Кількість змінних і значень має збігатися
- У Go важливо, щоб кількість змінних зліва збігалася з кількістю значень справа.
- Правильно:
```Go
a, b := 10, 20
```
- Тут дві змінні і два значення.
- Неправильно:
```Go
a, b := 10
```
- **Тут дві змінні, але тільки одне значення.**
- Неправильно:
```Go
a := 10, 20
```
- **Тут одна змінна, але два значення.**
### Навіщо це використовують
- Такий спосіб зручний, коли потрібно швидко створити кілька змінних.
- Це зменшує кількість коду та допомагає логічно групувати пов’язані змінні.
### Використання кілька присвоєнь
- Такий запис добре підходить, коли змінних небагато і вони логічно пов’язані.
- Наприклад:
```Go
x, y := 10, 20
```
- або:
```Go
firstName, lastName := "Ihor", "Kotov"
```
- або коли потрібно поміняти значення місцями:
```Go
a, b := 1, 2  
a, b = b, a
```
## Глобальні та локальні змінні в Go
### Що таке область видимості змінної
- **Область видимості змінної** — це частина програми, у якій можна звертатися до цієї змінної.
> Область видимості показує, де змінна доступна в коді.
- Не всі змінні можна використовувати в будь-якому місці програми. **Одні змінні доступні майже всюди, а інші — тільки всередині певної функції.**
- У Go є два основні варіанти:

|Тип змінної|Де створюється|Де доступна|
|---|---|---|
|Глобальна змінна|поза функціями|у всьому пакеті|
|Локальна змінна|всередині функції|тільки всередині цієї функції|
### Глобальна змінна
- **Глобальна змінна** — це змінна, яка оголошена поза функціями.
- Наприклад:
```Go
var g = "global"
```
- Ця змінна знаходиться не всередині `main()` і не всередині іншої функції, тому вона є глобальною.
- Приклад:
```Go
package main

import "fmt"

var g = "global"

func main() {
    fmt.Println(g)
}
```
- Змінна `g` доступна у функції `main()`, тому що вона оголошена на рівні пакета.
### Локальна змінна
- **Локальна змінна** — це змінна, яка створена всередині функції.
- Наприклад:
```Go
func printLocal() {
    l := "local"
    fmt.Println(l)
}
```
- Тут змінна `l` є локальною, тому що вона створена всередині функції `printLocal()`.
- Вона доступна тільки всередині цієї функції.
### Приклад глобальної та локальної змінної
```Go
package main

import "fmt"

var g = "global"

func printLocal() {
    l := "local"
    fmt.Println(l)
}

func main() {
    printLocal()
    fmt.Println(g)
}
```
- Результат:
```Go
local  
global
```
- `var g = "global"` — це глобальна змінна. Вона створена поза функціями.
- `l := "local"` — це локальна змінна. Вона створена всередині функції `printLocal()`.
- Функція `printLocal()` виводить локальну змінну `l`. Потім у `main()` виконується `fmt.Println(g)` і програма виводить глобальну змінну `g`.
### Глобальну змінну можна використовувати всередині функції
- Оскільки **глобальна змінна** оголошена поза функціями, її можна використовувати в інших функціях цього пакета.
- Приклад:
```Go
package main

import "fmt"

var g = "global"

func printLocal() {
    l := "local"
    fmt.Println(l)
    fmt.Println(g)
}

func main() {
    printLocal()
    fmt.Println(g)
}
```
- Результат:
```Go
local
global
global
```
- Хоча `g` не була створена всередині `printLocal()`, вона все одно доступна, бо оголошена глобально.
### Локальну змінну не можна використовувати поза функцією
- Якщо змінна створена всередині функції, вона існує тільки в цій функції.
- Неправильний приклад:
```Go
package main

import "fmt"

var g = "global"

func printLocal() {
    l := "local"
    fmt.Println(l)
}

func main() {
    fmt.Println(l)
}
```
- Результат помилки:
```Go
undefined: l
```
> Змінна `l` не визначена в цьому місці програми.

- `l` була створена всередині функції `printLocal()`, а ми намагаємося використати її у функції `main()`. Функція `main()` не бачить локальну змінну `l`.
### Однакові імена глобальної та локальної змінної
- У Go можна мати глобальну і локальну змінну з однаковим ім’ям. Але це можуть бути **дві різні змінні**.
- Приклад:
```Go
package main

import "fmt"

var num1 = 5

func printNumbers() {
    num1 := 10
    num2 := 7

    fmt.Println(num1)
    fmt.Println(num2)
}

func main() {
    printNumbers()
    fmt.Println(num1)
}
```
- Результат:
```Go
10
7
5
```
#### Розбір цього прикладу
- Спочатку ми створюємо глобальну змінну. Вона має значення `5`.
```Go
var num1 = 5
```
- Потім у функції `printNumbers()` створюється локальна змінна з таким самим ім’ям. Це вже інша змінна, яка існує тільки всередині функції `printNumbers()`.
```Go
num1 := 10
```
- Тому всередині `printNumbers()`: `fmt.Println(num1)` виведе `10`. А у функції `main()` `fmt.Println(num1)` виведе `5`. Тому що `main()` бачить глобальну змінну `num1`, а не локальну змінну з `printNumbers()`.
### Локальна змінна може “перекрити” глобальну
- Коли всередині функції створюється локальна змінна з таким самим ім’ям, як глобальна, вона **перекриває** глобальну змінну всередині цієї функції.
- Наприклад:
```Go
var num1 = 5

func printNumbers() {
    num1 := 10
    fmt.Println(num1)
}
```
- Усередині `printNumbers()` ім’я `num1` означає локальну змінну зі значенням `10`. Глобальна змінна `num1` зі значенням `5` не змінюється.
### Чому локальні змінні використовують частіше
- У Go локальні змінні використовують частіше, ніж глобальні.

| Локальні змінні                           | Чому це добре                           |
| ----------------------------------------- | --------------------------------------- |
| існують тільки всередині функції          | менше шансів випадково змінити значення |
| легше зрозуміти, де вони використовуються | код простіше читати                     |
| не впливають на інші частини програми     | менше помилок                           |
| краще підходять для невеликих обчислень   | функція стає незалежнішою               |
- Глобальні змінні краще використовувати тільки тоді, коли значення справді потрібно багатьом частинам програми.
## Константи в Go
### Що таке константа
- **Константа** — це значення, яке не можна змінити після оголошення. Константи схожі на змінні, але головна різниця така:

| Змінна                            | Константа                  |
| --------------------------------- | -------------------------- |
| значення можна змінити            | значення змінити не можна  |
| оголошується через `var` або `:=` | оголошується через `const` |
- Приклад змінної:
```Go
name := "Sammy"
name = "Igor"
```
- Приклад константи:
```Go
const shark = "Sammy"
```
- Після цього змінити `shark` вже не можна.
### Навіщо потрібні константи
- **Константи** використовують для значень, які:
	- часто повторюються в програмі;
	- не повинні випадково змінюватися;
	- мають одне стабільне значення.
- Наприклад, ставка податку:
```Go
const taxRate = 0.2
```
- Якщо в програмі багато разів використовується податкова ставка, краще записати її в одному місці як константу.
- Тоді, якщо ставка зміниться, достатньо буде змінити тільки один рядок, а не шукати це число по всій програмі:
```Go
const taxRate = 0.25
```
### Оголошення константи
- Константа створюється за допомогою ключового слова `const`.
```Go
const shark = "Sammy"
fmt.Println(shark)
```
- Результат:
```Go
Sammy
```

| Частина   | Пояснення                             |
| --------- | ------------------------------------- |
| `const`   | ключове слово для створення константи |
| `shark`   | ім’я константи                        |
| `"Sammy"` | значення константи                    |
### Константу не можна змінити
- Якщо після створення константи спробувати змінити її значення, буде помилка.
- Неправильно:
```Go
const shark = "Sammy"  
shark = "Igor"
```
- Помилка:
```Go
cannot assign to shark
```
- **Це означає, що не можна присвоїти нове значення константі `shark`. Тобто константа після оголошення залишається незмінною.**
### Типізовані та нетипізовані константи
- У Go константи можуть бути:
1. нетипізовані
2. типізовані
#### Нетипізована константа
- **Нетипізована константа** — це константа, якій не вказали конкретний тип.
- Наприклад:
```Go
const year = 365
```
- Тут ми не написали `int`, `int32` або інший тип. Тому `year` — це **нетипізована числова константа**. Її можна використовувати з різними цілими типами, наприклад з `int` або `int32`.
#### Типізована константа
- **Типізована константа** — це константа, якій явно вказали тип.
- Наприклад:
```Go
const leapYear = int32(366)
```
- Тут `leapYear` має конкретний тип `int32`. Така константа вже не така гнучка. Вона працює тільки з сумісними типами.
### Приклад з константами
```Go
package main

import "fmt"

const (
    year     = 365
    leapYear = int32(366)
)

func main() {
    hours := 24
    minutes := int32(60)

    fmt.Println(hours * year)
    fmt.Println(minutes * year)
    fmt.Println(minutes * leapYear)
}
```
- Результат:
```Go
8760  
21900  
21960
```
#### Розбір оголошення констант
```Go
const (
    year     = 365
    leapYear = int32(366)
)
```
- Це групове оголошення констант. Тут створюються дві константи.

|Константа|Значення|Тип|
|---|--:|---|
|`year`|`365`|нетипізована|
|`leapYear`|`366`|`int32`|
#### Розбір змінних у `main`
```Go
hours := 24
```
- Go автоматично визначає тип `hours` як `int`, тому що `24` це ціле число.
```Go
minutes := int32(60)
```
- Тут ми явно вказали тип, тобто `minutes` має тип `int32`.
#### Розбір обчислення `hours * year`
```Go
fmt.Println(hours * year)
```

|Назва|Тип|
|---|---|
|`hours`|`int`|
|`year`|нетипізована константа|
- Оскільки `year` не має конкретного типу, Go може використати її як `int`. Тому вираз працює.
```Go
24 * 365 = 8760
```
```Go
8760
```
#### Розбір обчислення `minutes * year`
```Go
fmt.Println(minutes * year)
```

| Назва     | Тип                    |
| --------- | ---------------------- |
| `minutes` | `int32`                |
| `year`    | нетипізована константа |
- Оскільки `year` нетипізована, Go може використати її як `int32`. Тому вираз працює.
```Go
60 * 365 = 21900
```
```Go
21900
```
#### Розбір обчислення `minutes * leapYear`
```Go
fmt.Println(minutes * leapYear)
```

| Назва      | Тип     |
| ---------- | ------- |
| `minutes`  | `int32` |
| `leapYear` | `int32` |
- Обидва значення мають однаковий тип `int32`, тому операція працює без проблем.
```Go
60 * 366 = 21960
```
- Результат:
```Go
21960
```
#### Чому `hours * leapYear` дає помилку
- Неправильний приклад:
```Go
fmt.Println(hours * leapYear)
```

| Назва      | Тип     |
| ---------- | ------- |
| `hours`    | `int`   |
| `leapYear` | `int32` |
- У Go `int` і `int32` — це різні типи. Тому Go не дозволяє множити їх напряму.
```Go
invalid operation: hours * leapYear (mismatched types int and int32)
```
- Це означає, що неможливо виконати операцію, бо типи не збігаються: `int` і `int32`.
#### Перетворення типу
##### Варіант 1: перетворити `leapYear` в `int`
```Go
fmt.Println(hours * int(leapYear))
```
- Тепер обидва значення мають тип `int`.
##### Варіант 2: перетворити `hours` в `int32`
```Go
fmt.Println(int32(hours) * leapYear)
```
- Тепер обидва значення мають тип `int32`.
### Головна різниця між типізованою і нетипізованою константою

| Вид константи | Приклад                       | Особливість                                           |
| ------------- | ----------------------------- | ----------------------------------------------------- |
| Нетипізована  | `const year = 365`            | може підлаштовуватися під потрібний числовий тип      |
| Типізована    | `const leapYear = int32(366)` | має конкретний тип і працює тільки з сумісними типами |
